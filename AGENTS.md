# AGENTS.md

## Rules

- This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.
- Follow /stb-principles and SKILL_ISSUES.md when writing code and designing systems.
- No implicit state machines in code.
- Keep files under 200 lines and functions under 50 lines.
- Commit each verified change. Stage only the changed files.
- Use lowercase commit messages of six words or fewer, with no trailers.
- Never push or merge `main` without explicit permission.
